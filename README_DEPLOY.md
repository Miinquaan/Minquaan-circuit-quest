# CIRCUIT QUEST WEB – bản cập nhật

## Đã thay đổi
- Nhiệm vụ bám theo logic `final.ino`: DỄ / TRUNG BÌNH / KHÓ; BUILD / TARGET / METER.
- Phần nhiệm vụ hiển thị lại theo dạng: cần dùng, cách mắc nguồn, cách mắc tải, dụng cụ đo, mục tiêu.
- Dây A11/A12/A13 có hình SVG động; hình tự đổi theo các ô xung quanh. A11 = thẳng, A12 = góc L, A13 = chữ T.
- Khi đang chọn một linh kiện mà chạm thẻ khác trên bàn, thẻ trên bàn được chọn để gỡ; không bị khóa bởi lựa chọn linh kiện.
- Màn hình điện thoại dọc vẫn xếp dọc; khi xoay ngang, bố cục chuyển sang kiểu gần desktop.
- Kho linh kiện hỗ trợ ảnh thật của người dùng: `assets/cards/A01.png` … `A15.png`.

## GitHub Pages
Đặt `index.html`, `style.css`, `app.js` ở root repository. Giữ thư mục `assets/cards/` nếu muốn dùng ảnh riêng.

## Thêm ảnh linh kiện
Copy ảnh của bạn vào `assets/cards/` và đặt tên đúng mã A01…A15. Upload/commit lên GitHub. Không cần sửa code.
